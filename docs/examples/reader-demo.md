# my-read テキスト読書のサンプル

Markdown、Org、TXTの文書をTEXTタブで読めます。
日本語の文書にはmacOSの音声が自動的に選ばれます。

## 読み上げの操作

SPCで現在の文を読み上げます。
sで連続読み上げを始めます。
jとkで次の文、前の文へ移動できます。

### 見出しの先へ

連続読み上げは見出しを越えて、この本文へ進みます。
読書位置は自動的に保存されます。
ファイルを開き直すと、前回の位置から再開できます。

## 文書を切り替える

DIREDから別の文書を開くと、種類に合ったタブに表示します。
HTMLファイルはEWWでWebページとして表示します。
